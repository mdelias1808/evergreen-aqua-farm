# Evergreen Aqua Farm — Expense Manager

Static website for GitHub Pages.

## Features
- Daily expense entry
- Categories, payment method, notes
- Dashboard: today/month/all totals
- Date/category filtering
- Printable PDF report using browser Print -> Save as PDF
- JSON Backup/Restore
- LocalStorage only; no server/database required

## GitHub Pages
1. Create a public GitHub repository.
2. Upload `index.html` to the repository root.
3. Settings -> Pages -> Deploy from branch -> `main` -> `/ (root)` -> Save.
4. Open the generated GitHub Pages URL.

## Important
Data is stored in the browser's LocalStorage. Keep regular backups, especially before clearing browser data or changing devices.
